# Calcolatore obiettivi agente immobiliare

Calcolatore interattivo per stimare obiettivi, conversioni e guadagni di un agente immobiliare.

Apri [`index.html`](./index.html) nel browser per usare il calcolatore.

Il pannello “Parte 5 - Calcolatore Provvigionale” stima il lordo 2027 per profilo. I conteggi per i profili Onboard e Junior sono annuali; per il Junior, la percentuale del regime si applica alla parte delle provvigioni variabili che supera il fisso annuo garantito di 12.000€.
